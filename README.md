# Portfólio — Bernardo Vieira

Portfólio pessoal em React e Vite, com foco em back-end, inteligência artificial e integração de sistemas.

## Executar localmente

Com Node.js e npm instalados:

```bash
npm install
npm run dev
```

Abra o endereço informado pelo Vite (normalmente http://127.0.0.1:5173).


O build gera a pasta `dist`, pronta para hospedagem estática. Não são necessárias variáveis de ambiente ou um servidor back-end.

## Conteúdo e manutenção

- `src/App.jsx`: apresentação, tecnologias por categoria, experiências, áreas de atuação, formação, idiomas e contatos.
- `src/styles.css`: identidade visual, layout responsivo e estilos de acessibilidade.
- `assets/bernardo.png`: imagem de perfil.
- `index.html`: título e descrição para mecanismos de busca.
